# PROJECT.md — Polyagent DevContainer

> Tier 1 base DevContainer template — multi-AI-agent parity environment.
> Governance: [AGENTS.md](AGENTS.md) (all three vendors; Claude reads it through [CLAUDE.md](CLAUDE.md))
> Commands: [REFERENCE.md](REFERENCE.md)

## Overview

Workspace-scoped environment for running Claude Code, Codex CLI, and Antigravity CLI in parity on the same project. Shared duties live in one hand-maintained `AGENTS.md` that every vendor reads. `.claude/` is the source of the rules, skills, and roles that the sync copies into the generated `.agents/rules` and `.agents/skills`; `.codex/` and the native `.agents/` files are hand-maintained per vendor. A new vendor reuses `AGENTS.md` and the generated copies instead of new governance text.

## Polyagent Parity Model

| Vendor | Hand-maintained | Generated by the sync |
|--------|-----------------|-----------------------|
| Claude Code | `AGENTS.md` (through `CLAUDE.md`), `CLAUDE.md`, `.claude/{rules,skills,hooks,agents}/`, `.claude/settings.json` | — |
| Codex CLI | `AGENTS.md`, `.codex/{config.toml,hooks.json,hooks/}` | `.agents/{rules,skills}/` |
| Antigravity CLI | `AGENTS.md`; native `.agents/rules.json`, `.agents/hooks.json`, `.agents/hooks/claude-hooks-adapter.sh` (runs `.claude/hooks/`) | `.agents/{rules,skills}/` |

Sync: `bash scripts/sync-agents-mirror.sh` — `.claude/` → `.agents/rules`, `.agents/skills` one-way generated mirror (copies edits; prunes orphans whose `.claude/` source was deleted; leaves the native `.agents/` files untouched).

## Environment

- **Template configuration**: `.devcontainer/.env` (build and startup values)
- **Persistent volumes**: `~/.claude` (Claude auth), `~/.codex` (Codex auth), `~/.gemini` (Antigravity auth, settings, conversations), `~/.config/antigravity` (Antigravity plugin/MCP secrets), `/commandhistory` (shell history)
- **Editor workspace settings**: `.vscode/` is tracked for VS Code convenience settings; it is not an agent vendor.
